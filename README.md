# Machine Learning Practice Notebooks

This repository contains a collection of Jupyter notebooks created during my practice and exploration of core machine learning concepts. The notebooks cover a range of topics from data preprocessing to model building and evaluation, serving as a hands‑on portfolio of applied ML techniques.

## 📂 Contents
- **Regression Models**  
  Linear and multiple regression exercises with evaluation metrics.

- **Classification Models**  
  Logistic regression, decision trees, and other classifiers applied to sample datasets.

- **Clustering & Unsupervised Learning**  
  K‑Means clustering and exploratory analysis of unlabeled data.

- **Data Preprocessing & Feature Engineering**  
  Handling missing values, scaling, encoding, and preparing datasets for modeling.

- **Visualization & EDA**  
  Using libraries like Matplotlib and Seaborn to explore datasets and visualize model results.

## ⚙️ Requirements
The notebooks use common Python libraries:
- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`
- `scikit-learn`

Install dependencies with:
```bash
pip install -r requirements.txt
```
